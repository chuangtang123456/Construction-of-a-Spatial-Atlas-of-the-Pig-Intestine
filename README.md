****A Spatial and Single-Cell Transcriptomic Atlas of the Pig Intestine****

**Overview**

This repository contains the analysis code used in the study:
A Spatial and Single-Cell Transcriptomic Atlas of the Pig Intestine Reveals Regional Organization and Microbiota-Associated Remodeling.
The repository provides the main computational workflows, analysis parameters, and scripts used to process and analyze the spatial transcriptomics and single-cell RNA sequencing (scRNA-seq) data presented in this study.
The code is organized into different directories according to the corresponding analytical procedures, including sample metadata, spatial transcriptomic analysis, and single-cell transcriptomic analysis.

**Data Availability**

All raw spatial transcriptomics and single-cell RNA sequencing data generated in this study have been deposited in the China National Center for Bioinformation (CNCB) under the project accession number:
PRJCA035296

**1. Sample_metadata/**

This directory contains the datasets and metadata used throughout the analyses, including:

Sample information and metadata for the datasets included in this study.

Spatial transcriptomics annotation results.

Single-cell RNA sequencing annotation results.



**2. Spatial/**

This directory contains the main scripts and parameters used for spatial transcriptomic data processing, analysis, and visualization.
It includes the key computational steps and corresponding parameters used to generate the spatial transcriptomics results presented in the study.

**3. Single_cell/**

This directory contains the main scripts and parameters used for single-cell RNA sequencing data processing, analysis, and visualization.
It includes the key computational workflows and corresponding parameters used to generate the scRNA-seq results presented in the study.
